## 3. 发现的提权配置

### 3.1 兼容性设置（AppCompatFlags\Layers）—— 无游戏条目

`HKCU\Software\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Layers` 全部内容只有 2 条，均与游戏无关：

```
<USERPROFILE>\AppData\Local\...\OneDrive.exe => ~ PERPROCESSSYSTEMDPIFORCEOFF
C:\Program Files (x86)\letsvpn\LetsPRO.exe                 => RunAsAdmin
```

`HKLM\...\AppCompatFlags\Layers` 与 `HKLM\...\WOW6432Node\...\Layers` 均为空。

→ **游戏没有通过"兼容性 → 以管理员身份运行此程序"被提权。**

### 3.2 EXE 内嵌 Manifest 的 requestedExecutionLevel

用 `LoadLibraryEx(LOAD_LIBRARY_AS_DATAFILE)` + `FindResource(RT_MANIFEST)` 只读提取，**未执行任何代码**：

| 可执行文件 | requestedExecutionLevel | 说明 |
|---|---|---|
| `mhtab.exe` | **asInvoker** | 游戏主程序，本身不要求提权 |
| `mhmain.exe` | **asInvoker** | 主逻辑，本身不要求提权 |
| **`my.exe`** | **requireAdministrator** | **唯一要求提权的文件** |

未发现外部 `.manifest` 文件（`<GAME_DIR>` 递归搜索为空），说明都是内嵌清单。

## 4. 提权来源分析

| 假设 | 判定 | 理由 |
|---|---|---|
| 用户兼容性设置（"以管理员身份运行"） | **排除（Confirmed 无此项）** | Layers 无游戏条目；快捷方式无 RunAs 标记 |
| 启动器主动请求提权 | **成立（Confirmed）** | `my.exe` Manifest = `requireAdministrator` |
| 游戏本体 Manifest 要求 | **排除（Confirmed）** | `mhtab`/`mhmain` 均 `asInvoker` |
| 计划任务 / 服务以高权限拉起 | **排除（Confirmed）** | 计划任务与服务均无相关项 |
| 子进程继承父进程令牌 | **成立（机制成立，关系 Likely）** | Windows 默认行为：子进程继承父进程令牌；父 PID 10968 已退出，无法直接验证其身份 |

**最可能的完整因果链**：

> 用户双击「梦幻西游.lnk」→ 启动 `my.exe` → Manifest 要求管理员 → UAC 确认 → `my.exe` 以 High IL 运行 → 由它拉起 `mhtab.exe` → 子进程继承 High IL → 后续 `mhmain`/`mhrender`/`xyqsvc` 全部为 High。

也就是说：**提权是"启动器声明 + 进程继承"的结果，不是游戏客户端自身的要求。**

## 5. 是否适合进一步测试普通权限启动

### 5.1 技术可行性

| 路径 | 可行性 | 说明 |
|---|---|---|
| 直接运行 `<GAME_DIR>\mhtab.exe` | 技术上可行（asInvoker） | 不触发 UAC，理论上以 Medium IL 启动 |
| 运行 `<GAME_DIR>\bin\my_new.exe` | 技术可行（asInvoker） | 但用途未知，可能是更新/辅助程序而非启动器 |
| 右键"以管理员身份运行"取消 | 不适用 | 快捷方式本来就没有勾选 |
| 修改 Manifest / Layers 强制降权 | **不允许** | 属于修改程序或系统配置，违反本次约束 |

### 5.2 风险评估

| 风险 | 等级 | 说明 |
|---|---|---|
| 启动器功能缺失 | 中 | `my.exe` 可能负责**版本更新、补丁校验、登录鉴权**；绕过它直接跑 `mhtab.exe` 可能导致更新失败或无法登录 |
| 反外挂判定异常 | **中高** | 非官方入口启动可能被客户端/反作弊视为异常环境，存在**账号风险**，这是最需要谨慎的一项 |
| 进程/文件锁冲突 | 中 | 现有游戏实例仍在运行，再启动可能提示"已在运行"或产生文件占用 |
| 数据损坏 | 低 | 正常启动流程不写入关键数据，但异常退出可能影响本地缓存 |

### 5.3 建议

**不建议**现在自动尝试。若确实要验证，建议按下述"最小风险"方式进行，且需要你明确批准：

1. 先**正常退出当前游戏**（而不是结束进程）；
2. 记录当前版本号与登录状态；
3. 以普通权限双击 `mhtab.exe`（或 `bin\my_new.exe`），观察：
   - 是否弹出 UAC（预期：不弹）
   - 进程 IL 是否变为 Medium（用同一套只读 API 复查）
   - 是否能正常登录进入游戏
4. 若出现任何异常提示（更新失败、鉴权失败、反作弊告警），**立即退出并回到官方快捷方式**。

> 说明：这一步会**改变当前环境**（需要退出并重开游戏），按你的安全限制，必须先得到你的批准才能执行。
