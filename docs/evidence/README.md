## 4. 导出流程（需 Founder 批准）

1. 明确要导出的**具体文件清单**与用途。
2. 逐张检查并裁掉窗口边框、浏览器标签栏、任务栏等非必要区域。
3. 放在 `tests/fixtures/<模块>/` 或 `docs/evidence/<poc>/` 下，文件名保持可追溯。
4. 在 `.gitignore` 中为该目录添加例外（当前 `*.png` 被全局忽略）。
5. 在 PR 描述中说明：导出了哪些、裁剪了什么、为什么必要、敏感性审查结论。
6. Founder / CTO 审核后合并。
